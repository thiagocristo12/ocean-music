# Ocean Music

Plataforma web interativa para auxiliar no aperfeiçoamento musical.
Projeto de TCC: Análise e Desenvolvimento de Sistemas.

## Tecnologias
React · Vite · Tailwind CSS 3.4 · Node.js (sem Express) · PostgreSQL · Git/GitHub

## Estrutura
- `frontend/` — aplicação React
- `backend/` — API Node.js (a partir da Etapa 12)
- `docs/` — documentação e diário de decisões

## Como rodar o front-end
    cd frontend
    npm install
    npm run dev
